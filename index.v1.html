    SPARC 알고리즘 — Sparse Peer-Assisted Rendezvous & Correction

    각 로봇은 중앙 서버 없이 자기 센서와 통신 반경 안의 이웃 정보만으로 판단합니다. 매 스텝, 모든 로봇이 병렬·비동기로 아래를 수행합니다.

    1. 오도메트리 적분 — x̂ ← x̂ + R(θ̂)·Δ. 자이로 바이어스로 헤딩 오차가 쌓여 위치가 점점 틀어지고, 불확실성 σ가 이동거리에 비례해 커집니다.
    2. 키프레임 — 새 장소에 들어가면 {x̂, σ, 장소 디스크립터 d}를 저장합니다.
    3. 통신 그래프 — 거리 R 이내 로봇끼리만 링크. 연결된 그룹마다 최소 ID 로봇이 브로커가 됩니다.
    4. 희소 교환 — 이웃에게 새 디스크립터만(256 B/개) 보냅니다. 전체 지도(키프레임당 ~48 KB)를 보내는 방식과 통신량을 실시간 비교합니다.
    5. 루프클로저 후보 — 디스크립터가 일치하면 "같은 장소를 봤다"는 후보가 생깁니다.
    6. 예산 제한 검증 — 브로커는 불확실성 σa²+σb²가 큰 후보부터 초당 K개만 기하 검증합니다. 비슷하게 생긴 다른 장소(오인식)는 여기서 기각됩니다.
    7. 포즈 그래프 융합 — x* = (x̂a/σa² + x̂b/σb²) / (1/σa² + 1/σb²). 두 로봇의 궤적을 마지막 앵커부터 선형으로 보정하고 σ를 줄입니다.
    8. 행동 결정 — σ > τ 이면 랑데부(가장 확실한 이웃을 따라가거나 마지막 만남 장소·기지로 복귀), 아니면 프런티어 탐사(공유 커버리지에서 미탐사 셀, 이웃 목표와 겹치지 않게).
    9. 조향 — 목표 추종 + 분리 + 장애물 회피 (로컬 센싱만 사용).
    for each robot i  (parallel, async):
  x̂ᵢ, σᵢ ← odometry(uᵢ)
  if entered_new_place(): Kᵢ.add(x̂ᵢ, σᵢ, d)
  for j in N(i) = { j : |xᵢ − xⱼ| < R }:
      send(j, Kᵢ.new_descriptors())    # sparse
      candidates += match(Kᵢ, Kⱼ)
  if i == min_id(component(i)):        # broker
      for c in top_K(candidates, σa²+σb²):
          if verify(c): fuse(c)        # σ ↓
  goal ← σᵢ > τ ? rendezvous() : frontier()
  vᵢ ← steer(goal) + separation + avoid

    Swarm-SLAM에서 가져온 개념: 희소 디스크립터 교환, 로봇 간 루프클로저, 연결 그룹별 브로커, 통신 예산 안에서 후보 우선순위화.
    새로 추가한 부분: 불확실성 기반 랑데부 행동, 공유 커버리지 기반 프런티어 분산, Boids·대형 제어와의 통합.

    시뮬레이션용 단순화: 2D 평면, 장소 인식은 격자 셀 디스크립터 + 오인식률로 근사, 원 논문의 대수적 연결성 기반 후보 선택과 분산 포즈그래프 최적화는 σ 우선순위와 가중평균 융합으로 근사했습니다.

    참고: P.-Y. Lajoie & G. Beltrame, “Swarm-SLAM”, IEEE RA-L 9(1), 2024 · MISTLab/Swarm-SLAM · C. W. Reynolds, “Flocks, Herds, and Schools”, SIGGRAPH 1987
